\texttt{AdminUser\ab Controller} & REST API controller (\texttt{/api/v1/admin/users}) enabling \texttt{SYSTEM\_ADMIN} and \texttt{SCHOOL\_ADMIN} to query paginated user lists, update user roles, deactivate accounts, and bulk-restore soft-deleted users. \\

\hline
\texttt{SchoolSubscription\ab GuardInterceptor} & Spring MVC \texttt{Handler\ab Interceptor} enforcing B2B tenant guards: blocks institutional requests when the user's \texttt{School} is \texttt{SUSPENDED}, \texttt{INACTIVE}, or outside its \texttt{01/09}--\texttt{31/05} subscription window. \\
\hline
\texttt{AuthService} / \texttt{AuthServiceImpl} & Core authentication service interface and implementation managing BCrypt password verification, dual-token issuance, token revocation via \texttt{lastToken\ab ResetAt}, and SHA-256 hashed password reset tokens. \\
\hline
\texttt{GoogleOAuth\ab ServiceImpl} & Processes Google OAuth 2.0 SSO callbacks, auto-provisions first-time \texttt{CUSTOMER} accounts with random BCrypt passwords, and dispatches credentials via \texttt{GoogleOAuth\ab PasswordEmail\ab Service}. \\
\hline
\texttt{JwtTokenProvider} & Cryptographic utility built on \texttt{jjwt 0.12.5} for signing and parsing access and refresh JWTs containing \texttt{uid}, \texttt{role}, and \texttt{schoolId} claims. \\
\hline
\texttt{UserRepository} & Spring Data JPA repository providing query methods for active/deleted users by email, username, school tenant, and password reset token hash. \\
\hline
\texttt{User} & Core JPA domain entity mapped to \texttt{"user"}, encapsulating identity, 6-role RBAC (\texttt{UserRole}), \texttt{AccountStatus}, B2C/B2B token counters, and audit timestamps. \\
\hline

\hline
\texttt{School}, \texttt{Classroom}, \texttt{ClassStudent}, \texttt{TokenBoost\ab Request} & Persistent JPA domain entities modeling the multi-tenant school hierarchy, classroom rosters, and daily token boost requests. \\
