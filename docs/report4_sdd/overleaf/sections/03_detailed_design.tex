\textbf{Class} & \textbf{Description} \\

\hline
AdminUser\ab Controller & REST API controller (/api/v1/admin/users) enabling SYSTEM\_ADMIN and SCHOOL\_ADMIN to query paginated user lists, update user roles, deactivate accounts, and bulk-restore soft-deleted users. \\

\hline

\hline
SchoolSubscription\ab GuardInterceptor & Spring MVC Handler\ab Interceptor enforcing B2B tenant guards: blocks institutional requests when the user's School is SUSPENDED, INACTIVE, or outside its 01/09--31/05 subscription window. \\
\hline
AuthService / AuthServiceImpl & Core authentication service interface and implementation managing BCrypt password verification, dual-token issuance, token revocation via lastToken\ab ResetAt, and SHA-256 hashed password reset tokens. \\
\hline
GoogleOAuth\ab ServiceImpl & Processes Google OAuth 2.0 SSO callbacks, auto-provisions first-time CUSTOMER accounts with random BCrypt passwords, and dispatches credentials via GoogleOAuth\ab PasswordEmail\ab Service. \\
\hline
JwtTokenProvider & Cryptographic utility for signing and parsing access and refresh JWTs containing uid, role, and schoolId claims. \\
\hline
UserRepository & Spring Data JPA repository providing query methods for active and deleted users by email, username, school tenant, and password reset token hash. \\
\hline
User & Core JPA domain entity mapped to "user", encapsulating user identity, role authorization (UserRole), AccountStatus, B2C/B2B token counters, and audit timestamps. \\
\hline

\hline
\rowcolor{tableheader}
\textbf{Class} & \textbf{Description} \\
\hline
\endhead

\hline
Classroom\ab Controller / ClassroomStudent\ab Controller & REST API controllers managing school classrooms, teacher assignments, student roster listings, classroom transfers, and smart class join codes (SmartClassCode\ab Generator). \\

AcademicLifecycle\ab ServiceImpl & Executes end-of-year academic promotions: promotes Grade 6--11 classrooms, archives completed cohorts, and transitions graduating Grade 12 student accounts to DEACTIVATED. \\
\hline
StudentImport\ab ServiceImpl & Coordinates SchoolWide\ab ImportProcessor and ClassroomImport\ab Processor using Apache Commons CSV to batch-create student accounts and auto-exempt past-deadline classroom assignments. \\
\hline
DailyToken\ab AllowanceServiceImpl & Enforces B2B student daily token limits with lazy midnight resets, resolving effective limits from classroom overrides or school defaults plus approved daily bonus tokens. \\
\hline
TokenBoostRequest\ab ServiceImpl & Manages the student daily token boost lifecycle (PENDING $\rightarrow$ APPROVED/REJECTED), deducting approved tokens from the school's shared unallocated\ab TokenQuota. \\
\hline
School, Classroom, ClassStudent, TokenBoost\ab Request & Persistent JPA domain entities modeling the multi-tenant school hierarchy, classroom rosters, and daily token boost requests. \\

Gamification\ab ServiceImpl & Tracks consecutive daily login streaks (DailyCheckIn) and quest progress (UserQuest\ab Progress) across CHAT, QUIZ, and READ\_CONTEXT activities. \\
