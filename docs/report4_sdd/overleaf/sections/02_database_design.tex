\section{Database Design}

\subsection{Entity-Relationship Diagram (Logical \& Physical ERD)}

The HistoryTalk persistence layer is built on \textbf{PostgreSQL 16} (relational schema \texttt{historical\_schema}) integrated with \textbf{Supabase PgVector} (vector extension \texttt{vector(768)} with HNSW indexing). Schema evolution is strictly version-controlled through \textbf{Flyway Migrations (\texttt{V1} to \texttt{V38})}. Across all 6 bounded domains, the database comprises \textbf{32 tables} (30 JPA entity tables, 1 many-to-many join table \texttt{context\_character\_mapping}, and 1 vector store table \texttt{vector\_chunk}).
