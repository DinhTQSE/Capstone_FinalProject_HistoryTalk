\section{Database Design}

\subsection{Entity-Relationship Diagram}

The HistoryTalk persistence layer is built on PostgreSQL (relational schema historical\_\ab schema) integrated with Supabase PgVector (vector extension vector(768) with HNSW indexing). Schema evolution is version-controlled through Flyway database migrations. Across the system's bounded domains, the database comprises the relational domain tables and the vector\_\ab chunk vector store table.
