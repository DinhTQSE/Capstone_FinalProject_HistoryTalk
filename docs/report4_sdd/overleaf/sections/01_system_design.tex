\section{System Design}

\subsection{System Architecture}

HistoryTalk is architected as a cloud-native, decoupled microservices platform serving both \textbf{B2B Educational Institutions} (Multi-tenant Schools, Classrooms, Teachers, and School Students) and \textbf{B2C Self-Directed Learners} (Customers). The architecture separates high-throughput transactional business operations, role-based access control (RBAC), and institutional lifecycle management from compute-intensive Retrieval-Augmented Generation (RAG), vector similarity search, cross-encoder reranking, and streaming Large Language Model (LLM) roleplay inference.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.98\textwidth]{figures/arch_system_overview.png}
    \caption[HistoryTalk System Architecture Overview]{HistoryTalk System Architecture Overview (Microservices, Data Stores \& Third-Party Integrations)}
    \label{fig:arch_system_overview}
\end{figure}

As illustrated in Figure~\ref{fig:arch_system_overview}, the system comprises four primary architectural tiers and seven external service integrations:

\begin{enumerate}[leftmargin=*]
    \item \textbf{Client Tier (Next.js / React Web Application):} Provides role-tailored workspaces for six distinct actors (\texttt{CUSTOMER}, \texttt{SCHOOL\_\ab STUDENT}, \texttt{TEACHER}, \texttt{SCHOOL\_\ab ADMIN}, \texttt{CONTENT\_\ab ADMIN}, and \texttt{SYSTEM\_\ab ADMIN}). It renders interactive GeoJSON battle maps, 3D historical character models (\texttt{.glb}), Server-Sent Events (SSE) streaming AI dialogues, multi-type quizzes, and classroom gradebooks.
    \item \textbf{Core Business Microservice (Java 21 / Spring Boot 3.2.5):} Acts as the central transactional backbone and API Gateway for client traffic. It enforces stateless JWT authentication (\texttt{Jwt\ab Authentication\ab Filter}), school academic-year subscription guards (\texttt{School\ab Subscription\ab Guard\ab Interceptor}), multi-tenant data isolation by \texttt{school\_id}, PDF text/OCR extraction (\texttt{Apache PDFBox 3.0.1} and \texttt{Tess4J 5.10.0}), PayOS webhook fulfillment, and Flyway schema migrations (\texttt{V1}--\texttt{V38}).
    \item \textbf{AI \& Hybrid RAG Microservice (Python 3.11 / FastAPI / Uvicorn):} A dedicated asynchronous AI engine protected by an internal API key (\texttt{X-Internal-\ab Api-Key}). It executes dynamic 80th-percentile semantic chunking, generates 768-dimensional dense embeddings (\texttt{BAAI/\ab bge-m3}), queries \texttt{Supabase PgVector}, invokes the \texttt{Kaggle Cross-Encoder Reranker}, and streams grounded 1st-person historical persona responses with Socratic reverse-questioning.
    \item \textbf{Data Persistence \& Vector Storage Tier:} Combines \textbf{PostgreSQL 16} (housing 31 relational tables in \texttt{historical\_\ab schema}) with \textbf{Supabase PgVector} (storing the \texttt{vector\_\ab chunk} table indexed with HNSW cosine distance \texttt{m=16, ef\_\ab construction=64} and the \texttt{match\_\ab history\_\ab chunks} RPC function).
    \item \textbf{External Third-Party Integrations:} Includes \textbf{Google OAuth 2.0} (SSO), \textbf{Cloudflare R2 / Supabase S3 Storage} (binary media, PDFs, 2D images, 3D GLB models), \textbf{PayOS Payment Gateway} (VietQR checkout and HMAC-SHA256 webhooks), \textbf{SMTP Mail Server} (transactional emails), \textbf{Ollama / OpenAI-Compatible LLM Host}, \textbf{Kaggle Reranker Service}, and the \textbf{Prometheus + Grafana Observability Stack}.
\end{enumerate}
