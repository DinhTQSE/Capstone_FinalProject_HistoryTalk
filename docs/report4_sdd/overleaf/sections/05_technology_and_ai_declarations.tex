2 & \textbf{Models \& Versions} &
$\bullet$ \textbf{Primary Roleplay \& Title LLM:} \texttt{Gemma-2-9B-IT} (hosted via Ollama with \texttt{num\_ctx=8192}, \texttt{temperature=0.3}, \texttt{repeat\_penalty=1.15}) and configurable \textbf{External OpenAI-Compatible API} (\texttt{LLM\_PROVIDER=\ab ollama|external} in \texttt{settings.py}).\newline
$\bullet$ \textbf{Dense Embedding Model:} \texttt{BAAI/bge-m3} (768-dimensional multilingual dense embeddings optimized for Vietnamese historical terminology).\newline
$\bullet$ \textbf{Cross-Encoder Reranker:} Hosted \textbf{Kaggle Cross-Encoder Reranker} (\texttt{/api/rerank}) scoring query--passage pairs.\newline
$\bullet$ \textbf{Document OCR Model:} \textbf{Tesseract 5 / Tess4J 5.10.0} with Vietnamese language pack (\texttt{vie.traineddata}). \\
\hline

3 & \textbf{End-to-End RAG Pipeline} &
$\bullet$ \textbf{Step 1 -- Hybrid Extraction:} \texttt{PdfType\ab Classifier} inspects uploaded PDFs; digital PDFs are extracted via \texttt{Apache PDFBox 3.0.1}, whereas scanned archival PDFs are routed to \texttt{OcrServiceImpl} (\texttt{Tess4J}).\newline
$\bullet$ \textbf{Step 2 -- Dynamic Semantic Chunking (\texttt{\_semantic\_\ab chunking}):} Splits text into sentences, computes \texttt{bge-m3} embeddings (concurrency semaphore $= 10$), calculates cosine distances between adjacent sentences, and splits chunks dynamically at the \textbf{80th percentile distance threshold} ($\ge 0.35$) or \texttt{max\_chunk\_\ab chars = 1200}.\newline
$\bullet$ \textbf{Step 3 -- Vector Indexing:} Generates 768-D embeddings (semaphore $= 15$) and batch-inserts (100 rows/batch) into \texttt{vector\_chunk} indexed with \textbf{PgVector HNSW} (\texttt{m = 16, ef\_\ab construction = 64}).\newline
$\bullet$ \textbf{Step 4 -- Filtered Retrieval \& Reranking (\texttt{retrieve\_\ab history\_\ab context}):} Embeds the user query, calls Supabase RPC \texttt{match\_history\_\ab chunks} (\texttt{match\_limit = 10}, filtered by \texttt{characterId}, \texttt{contextId}, and linked context/event UUIDs), and reranks the Top-10 candidates via the Kaggle Reranker API.\newline
$\bullet$ \textbf{Step 5 -- Grounded Persona Prompting \& Socratic Dialogue:} Injects retrieved passages into \texttt{build\_chat\_\ab system\_prompt}, enforces 1st-person Vietnamese pronouns ({\fontencoding{T5}\selectfont\textit{Ta, Trẫm, Tôi}}), applies a \textbf{30\% probability Socratic reverse-questioning directive} on follow-up turns, streams tokens via SSE, and generates 3 suggested follow-up questions. \\
\hline

4 & \textbf{Evaluation Metrics \& Target Thresholds} &
$\bullet$ \textbf{Streaming Latency (TTFT):} Time-To-First-Token $< 1.5\text{s}$ (95th percentile) under concurrent classroom load, monitored via \texttt{AiMetrics\ab Service} and Prometheus.\newline
$\bullet$ \textbf{Historical Faithfulness / Groundedness:} $\ge 95\%$ of factual claims in character responses must trace directly to retrieved \texttt{quotes\_used} from \texttt{vector\_chunk} or verified character biography.\newline
$\bullet$ \textbf{Out-of-Domain / Anti-Hallucination Refusal Rate:} $100\%$ refusal accuracy on anachronistic or unverified prompts (must acknowledge {\fontencoding{T5}\selectfont\textit{``Sử sách không ghi chép''}} instead of fabricating dates or events).\newline
$\bullet$ \textbf{Retrieval Recall@10:} $\ge 90\%$ recall of ground-truth historical passages on benchmark Vietnamese history QA pairs. \\
\hline

5 & \textbf{Fallback \& Resilience Mechanisms} &
$\bullet$ \textbf{Reranker Failure Fallback:} If the Kaggle Reranker API times out or returns HTTP 5xx, \texttt{retrieve\_\ab history\_\ab context} automatically falls back to the \textbf{Top-2 chunks by PgVector cosine similarity} (\texttt{texts[:2]}) without failing the chat request.\newline
$\bullet$ \textbf{Embedding Endpoint Fallback \& Backoff:} \texttt{get\_embedding\_\ab from\_ollama} implements 3-attempt exponential backoff ($1\text{s}, 2\text{s}, 3\text{s}$) and automatically falls back from \texttt{/api/embeddings} to \texttt{/api/embed} on HTTP 404.\newline
$\bullet$ \textbf{Dual LLM Provider Routing:} Supports zero-code switching between self-hosted \texttt{Ollama} and external \texttt{OpenAI-compatible} endpoints via environment configuration (\texttt{LLM\_PROVIDER}).\newline
$\bullet$ \textbf{Zero-Hallucination Prompt Guardrail:} When \texttt{rag\_context} is empty or does not contain the requested fact, strict RAG Instruction \#3 forces the character to state that historical records do not mention the detail rather than guessing. \\
